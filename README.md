# 🔐 Cybersecurity Demo Project

## A Complete Web Security Demonstration Platform

This project demonstrates real-world cybersecurity vulnerabilities and their fixes, including SQL injection, API security, penetration testing, and security auditing.

---

## 🎯 Project Overview

This application serves as an educational platform to understand:
- How attackers exploit web vulnerabilities
- How to implement proper security controls
- How to audit and harden web applications

The project includes both **vulnerable** (for learning) and **secure** (for best practices) versions side-by-side.

---

## 🚀 Quick Start

### Prerequisites
- Node.js (v16 or higher)
- npm (Node package manager)

### Installation & Running

```bash
# Clone the repository
git clone https://github.com/mnadeem2074/Cybersecurity-Demo-Project.git
cd Cybersecurity-Demo-Project

# Install dependencies
npm install

# Start the server
npm start
